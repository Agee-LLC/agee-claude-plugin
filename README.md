# Agee plugin for Claude

Agee is a case management platform for law firms. This plugin connects Claude to your firm's Agee account so you can work with your cases from a conversation. It connects only to Agee's own connector at https://mcp.agee.law.

## What you need

An active user account at a law firm that uses Agee. Each person signs in with their own Agee account.

## Install

In Claude on the web or desktop: Settings, Customize, Plugins, Add, Add from a repository, then enter `Agee-LLC/agee-claude-plugin`.

## Use with care

AI output can be wrong. Before legal advice based on it reaches a client, a qualified attorney must meaningfully review it, and the client must be clearly told AI was used to produce it.
